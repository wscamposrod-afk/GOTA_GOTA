## BASES DE DATOS
Es necesario contar con el programa Stata para poder trabajar con las bases de datos EMICRON 2024 ya unidas por la gestión del proyecto, teniendo en cuenta que:
1. El código dado para recibir los mismos resultados fue diseñado exclusivamente para este programa.
2. Si no cuenta con el programa, siempre puede dirigirse a la fuente original del DANE EMICRON 2024. Para descargar el tipo de archivo que corresponda.
3. Puede utilizar el documento finalizado en .do (como base para diseñar el código para su correspondiente análisis).
