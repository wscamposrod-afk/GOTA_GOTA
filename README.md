
# GOTA_GOTA
**PROYECTO DE INTERVENCIÓN:** Para reducir el uso de crédito informal (gota a gota).

## Beneficiarios principales
Propietarios de micronegocios del sector servicios de las principales ciudades del Caribe colombiano.

## Objetivo general
Diseñar una ruta diferenciada de intermediación y acompañamiento financiero que facilite el acceso al crédito formal y contribuya a reducir el uso del gota a gota.

## Objetivos específicos
1. Identificar las barreras de acceso al crédito formal.
2. Diseñar rutas diferenciadas de financiación según las condiciones de cada micronegocio.
3. Establecer mecanismos de acompañamiento, seguimiento y evaluación.

## Componentes del proyecto
1. Diagnóstico y caracterización financiera.
2. Identificación de barreras de acceso al crédito formal.
3. Diseño de rutas diferenciadas de financiación.
4. Acompañamiento y seguimiento financiero.
5. Evaluación de viabilidad y resultados.

## Rutas de intervención
- **Ruta 1:** Intermediación con entidades financieras.
- **Ruta 2:** Fortalecimiento de capacidades financieras.
    [Producto ACT 02](01_Formulacion/ISSUE 02/ACT-02_Identificacion_barreras_credito_formal.docx.pdf) 
- **Ruta 3:** Ahorro programado y acceso progresivo al crédito.
